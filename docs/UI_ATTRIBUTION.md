# UI attribution

The integrated app carries forward the ReLoop brand assets, Inter font, and responsive styles from the approved UI handoff. Its [original source and screenshots](https://github.com/bugfixer2627/ReLoop/tree/b67f1071b4f529e58f4313f75c3d307643a011ea/UI) are available in Git history.

- **ReLoop brand assets** — Wordmarks, infinity marks, process art, and waveform were supplied for use within the project owner's authorized scope. The brand kit came without a separate redistribution license.
- **Inter** — Copyright 2020 The Inter Project Authors. See the [SIL Open Font License 1.1](../public/brand/Inter-OFL.txt).
- **Spark Admin v1.0.0** — Spark Admin Dev and team. The [supplied source notice](licenses/Spark-Admin-source-README.md) records MIT coverage and ThemeWagon distribution.
- **Crypgo v1.0.0** — Getnext.jsTemplates. The [supplied source notice](licenses/Crypgo-source-README.md) records MIT coverage and ThemeWagon distribution. ReLoop uses its landing page composition.
- **Inline icons** — Carried over from the UI handoff's original icon components.
