# Template Comparison

## Spark Admin v1.0.0

Preserved: the 280px fixed forest sidebar, two-rem sidebar padding, uppercase navigation groups, muted links with a left lime active indicator, bottom profile card, 2.5rem main content padding, translucent sticky header, centered 480px search pill, dark Create action, square header actions, Spark's 24px card radius, white surfaces, light dashboard canvas, and centered login card with green background glows.

Adapted: Spark's Dashboard, Basic Tables, Forms & Input, and Login Screen content are replaced with ReLoop's feedback cases, claim findings, platform drafts, and clearly labeled demo controls. The Bootstrap markup is represented as reusable React components and scoped CSS inside the single Next.js app.

Could not reuse: the original Bootstrap runtime, Bootstrap Icons font, ApexCharts, Flatpickr, generic sales data, and Spark's complete static HTML pages are not imported globally. The prototype keeps one Tailwind-enabled Next.js application and uses its own line-icon component to avoid conflicting global frameworks.

Remaining visible differences: the chart is a CSS mock rather than ApexCharts, and notification/profile dropdowns are reduced to lightweight local controls. Those differences keep the prototype portable while preserving the visible layout geometry.

## Crypgo v1.0.0

Preserved: the dark marketing canvas, generous top navigation, centered navigation links, outlined/filled CTA pairing, 12-column hero composition, large white heading with lime emphasis, right-side product preview, generous vertical spacing, responsive mobile menu behavior, and blurred gradient background treatment.

Adapted: crypto copy, wallets, trading balances, app-store buttons, and cryptocurrency artwork are replaced with ReLoop's complaint-review message and a CSS-rendered workspace preview.

Could not reuse: Crypgo's crypto image assets, crypto-specific forms, auth/blog dependencies, and Framer Motion package are not copied. The landing keeps lightweight CSS transitions and the existing Next.js route links.

Remaining visible differences: the original Crypgo illustrations and exact font package are absent because they carry crypto-specific content and would require separate asset/license decisions. The composition and spacing remain the reference baseline.
